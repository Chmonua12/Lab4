### Лабораторная работа №4
## Солодовникова Милена К0709-23/3
Синхронизация потоков в .NET
Цель
Изучить взаимоблокировки (deadlock) и методы их предотвращения через классические задачи синхронизации.

## Задачи
Обедающие философы - реализовать и сравнить версии с deadlock и без

Спящий парикмахер - смоделировать работу с ограниченной очередью

Производитель-Потребитель - организовать работу с ограниченным буфером

## Файлы
DiningPhilosophersDeadlock.cs - версия с взаимоблокировкой

DiningPhilosophersNoDeadlock.cs - исправленная версия

SleepingBarber.cs - модель парикмахерской

ProducerConsumer.cs - Producer-Consumer с буфером


## Что проверяется
Философы: deadlock в первой версии, корректная работа во второй

Парикмахер: работа с ограниченной очередью, синхронизация клиентов

Producer-Consumer: отсутствие переполнения буфера и попыток взять из пустого

## Технологии
SemaphoreSlim - ограничение доступа к ресурсам

lock - защита критических секций

BlockingCollection - автоматическая синхронизация

Thread - параллельные потоки

## Результат
Освоены основные примитивы синхронизации и методы предотвращения взаимоблокировок в многопоточных приложениях.
